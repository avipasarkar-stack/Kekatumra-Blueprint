माझं गाव केकतउमरा — TEST_STAGE25
===================================

## प्रकल्पाचा परिचय

केकतउमरा गावासाठी माहिती, लोकसहभाग, कुटुंब सर्वेक्षण आणि स्थानिक कौशल्यांची नोंद एकाच मराठी वेबसाइटमध्ये मांडणारा हा Stage 25 प्रकल्प आहे. सर्वेक्षण व व्यवस्थापनाची कामे सर्वांसाठी खुली आहेत.

सार्वजनिक सूचना, कामगार आणि रेटिंगसाठी backend वापरला जातो. कुटुंब सर्वेक्षणाच्या नोंदी backend च्या SQLite डेटाबेसमध्ये साठवल्या जातात.

## मुख्य विभाग आणि सुविधा

- **मुख्यपृष्ठ:** गावाची ओळख आणि इतर विभागांकडे जाण्यासाठी दुवे.
- **गावाची माहिती:** परिचय, मूलभूत सुविधा आणि गावातील संस्थांसाठी माहितीचे प्रारूप.
- **गावाचा इतिहास:** स्रोतांसह इतिहास आणि स्थानिक आठवणी नोंदवण्यासाठी नमुना.
- **छायाचित्रे:** गाव, शाळा, विकासकामे आणि कार्यक्रमांसाठी गॅलरीची जागा.
- **गाव विकास:** विकासकामे, स्थिती आणि टिपांसाठी तक्ता.
- **शेती व रोजगार:** शेती, कृषी सेवा, स्थानिक उद्योग आणि रोजगाराविषयी विभाग.
- **शासकीय योजना:** अधिकृत स्रोतांवरून अद्ययावत करावयाच्या योजनांची मांडणी.
- **शिक्षण व शाळा विकास:** विद्यार्थी सर्वेक्षण, पालकांच्या अपेक्षा आणि शाळा विकासाचे प्रारूप. वैयक्तिक विद्यार्थ्यांची माहिती सार्वजनिक न करण्याची सूचना दिली आहे.
- **कुटुंब सर्वेक्षण:** घर/कुटुंब माहिती, सदस्यांचे स्वतंत्र टॅब, जन्मतारखेवरून वय, नोंदी जतन व संपादन, शोध, डिलीट, डुप्लिकेट तपासणी, एकत्रित आकडेवारी, JSON बॅकअप आयात/निर्यात, CSV निर्यात आणि प्रिंट.
- **कौशल्य सेतू:** मंजूर व संपर्क-संमती असलेले कामगार शोधणे, कौशल्य श्रेणीने गाळणे आणि संपर्क साधणे.
- **गावविकास सूचना:** नागरिकांच्या सूचना नोंदवणे आणि प्रशासकीय मंजुरीनंतरच सार्वजनिक करणे.
- **कामगार नोंदणी व निर्देशिका:** कौशल्यधारकांची माहिती व संपर्क-संमती घेऊन नोंदणी; मंजुरीपूर्वी प्रोफाइल सार्वजनिक होत नाही.
- **कामगार रेटिंग:** अभिप्राय नोंदवणे आणि मंजुरीनंतर रेटिंग सारांशात समाविष्ट करणे.
- **प्रशासकीय विभाग:** सूचना, कामगार आणि रेटिंगची सार्वजनिक मंजुरी/नकार.

## फोल्डरमधील फाइल्स

- `index.html` — backend सर्व्हरवरून उघडायची वेबसाइट.
- `app.js` — नेव्हिगेशन आणि API संवादासाठी JavaScript.
- `styles.css` — वेबसाइटच्या शैलींची स्वतंत्र CSS प्रत. सध्याच्या `index.html` मधून ही फाइल लोड होत नाही.
- `Images/` — भविष्यातील छायाचित्रे/माध्यमांसाठी फोल्डर.
- `README.txt` — प्रकल्प, वापर आणि प्रगतीविषयी माहिती.
- `वाचा_आधी.txt` — पूर्वीच्या स्वतंत्र सदस्य संमती फॉर्मच्या प्रिंट मांडणीविषयी नोंद.

वेबसाइटची रचना व शैली `index.html` मध्ये आहेत; API संवाद आणि काही पृष्ठांची कार्ये `app.js` मध्ये आहेत. backend च्या `public` फोल्डरमध्ये चालवण्यासाठी बदल केल्यानंतर frontend sync पायरी चालवा.

## वेबसाइट सुरू करणे

1. Node.js 22.13 किंवा नवीन आवृत्ती स्थापित असल्याची खात्री करा.
2. PowerShell मध्ये प्रकल्पाच्या `backend` फोल्डरमध्ये जा: `cd backend`
3. `node scripts/sync-frontend.js` चालवा.
4. सर्व्हर सुरू करा: `node --disable-warning=ExperimentalWarning server.js`
5. ब्राउझरमध्ये `http://localhost:3000` उघडा.

`index.html` फाइल थेट उघडल्यास किंवा Live Server ने चालवल्यास API उपलब्ध होणार नाही; backend मधून दिलेला `http://localhost:3000` पत्ता वापरा. npm पॅकेज इन्स्टॉल करण्याची गरज नाही. अधिक तपशीलासाठी `backend/README.md` पहा.

## स्थानिक डेटा आणि बॅकअप

- कुटुंब नोंदी `backend/data/kekatumra.db` या SQLite डेटाबेसमध्ये साठवल्या जातात. त्या पाहणे व बदलणे सर्वांसाठी खुले आहे.
- कुटुंब सर्वेक्षणातील **JSON डाउनलोड** कुटुंब नोंदींचा बॅकअप देतो. सूचना, कामगार आणि रेटिंगसाठी हा बॅकअप लागू होत नाही. **JSON बॅकअप तपासा** फाईलची चाचणी व विद्यमान कुटुंब नोंदींशी तुलना करतो; त्या प्रक्रियेत वेबसाइटमधील नोंदी बदलत नाहीत. **JSON बॅकअपमधून माहिती परत आणा** फक्त नवीन कुटुंब नोंदी जोडते; आधीच्या नोंदी overwrite किंवा delete करत नाही.
- CSV फाईलमध्ये कुटुंब आणि सदस्यांची वैयक्तिक माहिती असू शकते. ती सुरक्षित ठिकाणी ठेवा आणि अनधिकृत व्यक्तींना पाठवू नका.
- नियमित JSON बॅकअप घ्या; डेटाबेस फाइलची सुरक्षित प्रत ठेवण्याच्या सूचना `backend/README.md` मध्ये आहेत.

## सध्याची प्रगती

**Stage 25 स्थिती: सार्वजनिक API व डेटाबेस-सह चाचणी आवृत्ती.**

- मुख्य माहिती विभाग, प्रतिसादक्षम नेव्हिगेशन आणि नमुना सामग्री तयार आहे.
- कुटुंब नोंदी, सदस्यनिहाय फॉर्म, शोध/संपादन, डुप्लिकेट तपासणी, एकत्रित आकडेवारी, बॅकअप, CSV आणि प्रिंट प्रवाह जोडलेले आहेत.
- सूचना, कामगार नोंदणी, रेटिंग आणि प्रशासकीय मंजुरीसाठी backend प्रवाह जोडलेले आहेत.
- प्रत्यक्ष ब्राउझर, मोबाइल स्क्रीन, प्रिंट पूर्वदृश्य, बॅकअप पुनर्संचयित करणे आणि डेटा हरवण्याच्या परिस्थितींची स्वतंत्र स्वीकार चाचणी करणे बाकी आहे.

## मर्यादा आणि सुरक्षितता

- कुटुंबांची वैयक्तिक माहिती सर्वांसाठी खुली आहे; कोणीही ती पाहू, बदलू, निर्यात करू किंवा हटवू शकते. गोपनीयता/संमती व सार्वजनिक प्रवेशाचे परिणाम पूर्णपणे स्वीकारल्याशिवाय वास्तविक वैयक्तिक माहिती भरू नका.
- कुटुंब व विद्यार्थ्यांची नावे, जन्मतारखा, फोन क्रमांक किंवा अन्य संवेदनशील माहिती सार्वजनिक किंवा सामायिक संगणकावर टाकू नका.
- प्रत्यक्ष वापरापूर्वी HTTPS, वैध संमती प्रक्रिया, गोपनीयता/डेटा-धारण धोरण, सुरक्षित बॅकअप आणि पुनर्प्राप्ती चाचणी आवश्यक आहेत. सार्वजनिक access बंद करायचा असल्यास सर्व्हर-साइड परवानगी व्यवस्था पुन्हा लागू करावी.
- सरकारी योजना, गावाची आकडेवारी, इतिहास आणि विकासकामांची माहिती अधिकृत स्रोतांशी पडताळूनच प्रकाशित करावी.

## पुढील कामासाठी प्राधान्यक्रम

1. मोबाइल व डेस्कटॉपवर सर्व फॉर्म, नेव्हिगेशन आणि प्रिंट पूर्वदृश्य तपासणे.
2. Stage 25 storage keys चे migration, JSON आयात/तपासणी आणि CSV उघडण्याची चाचणी करणे.
3. HTML मधील inline CSS/JavaScript आणि स्वतंत्र `styles.css`/`app.js` यांची मालकी स्पष्ट करून duplicate source टाळणे.
4. अधिकृत वापरासाठी backend, सुरक्षित प्रमाणीकरण, डेटाबेस, प्रशासकीय अधिकार आणि audit log तयार करणे.
5. सर्वेक्षणापूर्वी संमतीपत्र, गोपनीयता सूचना आणि डेटा ठेवण्याचा कालावधी अधिकृतरीत्या मंजूर करणे.
6. अधिकृत गावमाहिती, पडताळलेली छायाचित्रे आणि योजनांचे ताजे स्रोत जोडणे.
