माझं गाव केकतउमरा — TEST_STAGE25
===================================

## प्रकल्पाचा परिचय

केकतउमरा गावासाठी माहिती, लोकसहभाग, कुटुंब सर्वेक्षण आणि स्थानिक कौशल्यांची नोंद एकाच मराठी वेबसाइटमध्ये मांडणारा हा स्वतंत्र Stage 25 चाचणी आराखडा आहे. ही आवृत्ती आधीच्या Stage 24 कामावर आधारित स्वतंत्र प्रत आहे. Stage 24 मधील मूळ फाइल्स बदलण्याचा हेतू नाही.

सध्याची वेबसाइट स्थिर HTML, CSS आणि JavaScript वापरते. सर्व्हर, केंद्रीय डेटाबेस किंवा ऑनलाइन खाते व्यवस्था जोडलेली नाही. त्यामुळे सर्वेक्षण, सूचना, कामगार, रेटिंग आणि प्रशासकीय मंजुरीची माहिती चालू ब्राउझरच्या `localStorage` मध्येच राहते.

## मुख्य विभाग आणि सुविधा

- **मुख्यपृष्ठ:** गावाची ओळख आणि इतर विभागांकडे जाण्यासाठी दुवे.
- **गावाची माहिती:** परिचय, मूलभूत सुविधा आणि गावातील संस्थांसाठी माहितीचे प्रारूप.
- **गावाचा इतिहास:** स्रोतांसह इतिहास आणि स्थानिक आठवणी नोंदवण्यासाठी नमुना.
- **छायाचित्रे:** गाव, शाळा, विकासकामे आणि कार्यक्रमांसाठी गॅलरीची जागा.
- **गाव विकास:** विकासकामे, स्थिती आणि टिपांसाठी तक्ता.
- **शेती व रोजगार:** शेती, कृषी सेवा, स्थानिक उद्योग आणि रोजगाराविषयी विभाग.
- **शासकीय योजना:** अधिकृत स्रोतांवरून अद्ययावत करावयाच्या योजनांची मांडणी.
- **शिक्षण व शाळा विकास:** विद्यार्थी सर्वेक्षण, पालकांच्या अपेक्षा आणि शाळा विकासाचे प्रारूप. वैयक्तिक विद्यार्थ्यांची माहिती सार्वजनिक न करण्याची सूचना दिली आहे.
- **कुटुंब सर्वेक्षण:** घर/कुटुंब माहिती, सदस्यांचे स्वतंत्र टॅब, जन्मतारखेवरून वय, नोंदी जतन व संपादन, शोध, डिलीट, डुप्लिकेट तपासणी, एकत्रित आकडेवारी, JSON बॅकअप आयात/निर्यात, CSV निर्यात आणि प्रिंट.
- **कौशल्य सेतू:** मंजूर व संपर्क-संमती असलेले कामगार शोधणे, कौशल्य श्रेणीने गाळणे आणि संपर्क साधणे.
- **गावविकास सूचना:** नागरिकांच्या सूचना नोंदवणे आणि प्रशासकीय मंजुरीनंतरच सार्वजनिक करणे.
- **कामगार नोंदणी व निर्देशिका:** कौशल्यधारकांची माहिती व संपर्क-संमती घेऊन नोंदणी; मंजुरीपूर्वी प्रोफाइल सार्वजनिक होत नाही.
- **कामगार रेटिंग:** अभिप्राय नोंदवणे आणि मंजुरीनंतर रेटिंग सारांशात समाविष्ट करणे.
- **प्रशासकीय विभाग:** स्थानिक चाचणीतील सूचना, कामगार आणि रेटिंग मंजुरी/नकारासाठी रांग. हे वास्तविक सुरक्षित प्रशासकीय लॉगिन नाही.

## फोल्डरमधील फाइल्स

- `index.html` — सध्या उघडून वापरायची वेबसाइट. पृष्ठरचना, शैली आणि बहुतांश कार्यरत JavaScript याच फाइलमध्ये समाविष्ट आहेत.
- `app.js` — नेव्हिगेशन आणि कौशल्य शोधाशी संबंधित JavaScript ची स्वतंत्र प्रत. सध्याच्या `index.html` मधून ही फाइल लोड होत नाही.
- `styles.css` — वेबसाइटच्या शैलींची स्वतंत्र CSS प्रत. सध्याच्या `index.html` मधून ही फाइल लोड होत नाही.
- `Images/` — भविष्यातील छायाचित्रे/माध्यमांसाठी फोल्डर.
- `README.txt` — प्रकल्प, वापर आणि प्रगतीविषयी माहिती.
- `वाचा_आधी.txt` — पूर्वीच्या स्वतंत्र सदस्य संमती फॉर्मच्या प्रिंट मांडणीविषयी नोंद.

`app.js` आणि `styles.css` यांना सक्रियपणे जोडायचे असल्यास HTML मधील inline कोड आणि या स्वतंत्र फाइल्स यांची एकच अधिकृत आवृत्ती ठरवूनच बदल करावेत. सध्या वेबसाइट तपासताना `index.html` हा निर्णायक स्रोत आहे.

## वेबसाइट सुरू करणे

1. `index.html` Chrome, Edge किंवा Firefox मध्ये उघडा.
2. अधिक सुसंगत स्थानिक वापरासाठी VS Code मधील Live Server किंवा इतर स्थिर फाइल सर्व्हर वापरा.
3. सर्वेक्षण नोंदी पाहण्यासाठी आणि स्थानिक चाचणीसाठी तोच ब्राउझर, प्रोफाइल आणि वेबसाइटचा पत्ता वापरा. फाइल थेट उघडल्यास ब्राउझरनुसार `localStorage` ची वागणूक वेगळी असू शकते.
4. वैयक्तिक सर्वेक्षणाची खरी माहिती या चाचणी आवृत्तीत भरू नका.

या प्रकल्पासाठी सध्या `npm install` किंवा इतर पॅकेज इन्स्टॉलेशन आवश्यक नाही. Devanagari अक्षररचनेसाठी Google Fonts वरील Noto Sans Devanagari वापरला आहे; इंटरनेट उपलब्ध नसल्यास ब्राउझर पर्यायी फॉन्ट वापरेल.

## स्थानिक डेटा आणि बॅकअप

- कुटुंब सर्वेक्षण, सूचना, कामगार आणि रेटिंग या सर्व नोंदी ब्राउझरच्या `localStorage` मध्ये असतात. त्या दुसऱ्या संगणकावर किंवा दुसऱ्या ब्राउझर प्रोफाइलमध्ये आपोआप उपलब्ध होत नाहीत.
- Stage 25 मध्ये कुटुंब सर्वेक्षण, मसुदे, सूचना, कामगार आणि रेटिंगसाठी स्वतंत्र Stage 25 storage keys वापरले जातात. संबंधित जुनी Stage 24 key उपलब्ध असेल आणि Stage 25 key अद्याप नसेल, तर पहिल्या उघडण्यावेळी जुन्या मूल्याची प्रत Stage 25 मध्ये केली जाते. पुढील Stage 25 बदल जुन्या key मध्ये लिहिले जात नाहीत.
- कुटुंब सर्वेक्षणातील **JSON डाउनलोड** कुटुंब नोंदींचा बॅकअप देतो. सूचना, कामगार आणि रेटिंगसाठी हा बॅकअप लागू होत नाही. **JSON बॅकअप तपासा** फाईलची चाचणी व विद्यमान कुटुंब नोंदींशी तुलना करतो; त्या प्रक्रियेत वेबसाइटमधील नोंदी बदलत नाहीत. **JSON बॅकअपमधून माहिती परत आणा** फक्त नवीन कुटुंब नोंदी जोडते; आधीच्या नोंदी overwrite किंवा delete करत नाही.
- CSV फाईलमध्ये कुटुंब आणि सदस्यांची वैयक्तिक माहिती असू शकते. ती सुरक्षित ठिकाणी ठेवा आणि अनधिकृत व्यक्तींना पाठवू नका.
- ब्राउझरचा डेटा साफ करणे, प्रोफाइल हटवणे किंवा साठवण मर्यादा संपणे यामुळे स्थानिक नोंदी हरवू शकतात. नियमित JSON बॅकअप घ्या.

## सध्याची प्रगती

**Stage 25 स्थिती: स्थानिक चाचणी आवृत्ती; प्रत्यक्ष सार्वजनिक/प्रशासकीय वापरासाठी तयार नाही.**

- मुख्य माहिती विभाग, प्रतिसादक्षम नेव्हिगेशन आणि नमुना सामग्री तयार आहे.
- कुटुंब नोंदी, सदस्यनिहाय फॉर्म, शोध/संपादन, डुप्लिकेट तपासणी, एकत्रित आकडेवारी, बॅकअप, CSV आणि प्रिंट प्रवाह जोडलेले आहेत.
- सूचना, कामगार नोंदणी आणि रेटिंगसाठी स्थानिक सबमिशन व ब्राउझर-आधारित मंजुरी प्रवाह जोडलेले आहेत.
- Stage 25 साठी स्वतंत्र `localStorage` नावे वापरली जातात.
- प्रत्यक्ष ब्राउझर, मोबाइल स्क्रीन, प्रिंट पूर्वदृश्य, बॅकअप पुनर्संचयित करणे आणि डेटा हरवण्याच्या परिस्थितींची स्वतंत्र स्वीकार चाचणी करणे बाकी आहे.

## मर्यादा आणि सुरक्षितता

- `localStorage` एन्क्रिप्टेड डेटाबेस नाही. त्यावरून वापरकर्त्यांची ओळख, प्रवेश नियंत्रण, ऑडिट किंवा सुरक्षित बॅकअप सुनिश्चित होत नाही.
- प्रशासकीय मंजुरी याच ब्राउझरमध्ये चालणारी नमुना प्रक्रिया आहे. ती अधिकार-नियंत्रण किंवा सर्व्हरवरील पडताळणीचा पर्याय नाही.
- सूचना, कामगार किंवा रेटिंगमध्ये संमती/मंजुरी तपासणीचा UI असला तरी स्थानिक डेटा वापरकर्ता बदलू शकतो. वास्तविक सार्वजनिक निर्देशिका म्हणून यावर अवलंबून राहू नये.
- कुटुंब व विद्यार्थ्यांची नावे, जन्मतारखा, फोन क्रमांक किंवा अन्य संवेदनशील माहिती सार्वजनिक किंवा सामायिक संगणकावर टाकू नका.
- प्रत्यक्ष वापरापूर्वी सुरक्षित सर्व्हर-साइड लॉगिन, भूमिका-आधारित परवानग्या, HTTPS, API, डेटाबेस, वैध संमती प्रक्रिया, गोपनीयता/डेटा-धारण धोरण, बॅकअप आणि पुनर्प्राप्ती चाचणी आवश्यक आहेत.
- सरकारी योजना, गावाची आकडेवारी, इतिहास आणि विकासकामांची माहिती अधिकृत स्रोतांशी पडताळूनच प्रकाशित करावी.

## पुढील कामासाठी प्राधान्यक्रम

1. मोबाइल व डेस्कटॉपवर सर्व फॉर्म, नेव्हिगेशन आणि प्रिंट पूर्वदृश्य तपासणे.
2. Stage 25 storage keys चे migration, JSON आयात/तपासणी आणि CSV उघडण्याची चाचणी करणे.
3. HTML मधील inline CSS/JavaScript आणि स्वतंत्र `styles.css`/`app.js` यांची मालकी स्पष्ट करून duplicate source टाळणे.
4. अधिकृत वापरासाठी backend, सुरक्षित प्रमाणीकरण, डेटाबेस, प्रशासकीय अधिकार आणि audit log तयार करणे.
5. सर्वेक्षणापूर्वी संमतीपत्र, गोपनीयता सूचना आणि डेटा ठेवण्याचा कालावधी अधिकृतरीत्या मंजूर करणे.
6. अधिकृत गावमाहिती, पडताळलेली छायाचित्रे आणि योजनांचे ताजे स्रोत जोडणे.
